## 2. 连带影响与处理

### 2.1 旧 push durable 升级兼容

实际启动时发现，已存在的 `im-inbound-worker` 是 push consumer，新 Worker 不能直接以 pull 方式绑定。已增加安全迁移：

- 读取旧 consumer ACK floor；
- 仅在检测到 push durable 时删除并重建；
- 新 pull consumer 从 `ack_floor.stream_seq + 1` 开始；
- 已 ACK 历史不重放，未 ACK 积压不跳过。

迁移后 NATS 实测为 `num_pending=0` 且存在 pull waiters。

### 2.2 测试语义更新

`你好` 现在是确定性快速路径，原“非法 LLM JSON”测试改用 `你是谁` 触发真实 LLM 路径。安全降级断言未改，仅避免测试被新快速路径短路。

### 2.3 持久化与实时广播边界

NATS Core 用于“在线实时广播”，不代替持久化。断线客户仍从 PostgreSQL 消息历史和游标恢复，JetStream 仍保留出站事件。
