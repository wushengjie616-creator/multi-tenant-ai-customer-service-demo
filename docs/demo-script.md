# 10–15 分钟面试演示剧本

## 演示目标

让面试官在 12 分钟内看到三件事：业务闭环真能跑、高并发/安全不是 PPT、候选人能说清 AI 与确定性代码的边界。

## 开始前

```bash
make up
curl http://localhost:8000/health/ready
```

打开：

- 主入口：<http://localhost:8000/ui/>
- 平台管理员：<http://localhost:8000/ui/platform.html>
- API 文档：<http://localhost:8000/docs>
- Prometheus：<http://localhost:8000/metrics>

## 录屏时间线

### 0:00–1:00：一句话架构

> 这是一套多租户教育 AI 客服后端。FastAPI 只做无状态接入，PostgreSQL 是事实源，NATS 削峰，Redis 承担限流、短期上下文和全局 LLM 准入，Qdrant 按 tenant_id 检索。LLM 只负责理解和话术，没有业务执行权。

展示 `/health/ready`，快速指出 Compose 中的应用、worker、scheduler、5 个 Mock 和 4 个基础设施。

### 1:00–2:30：多租户后台

进入平台管理员页，展示 5 个策展租户：

| 编号 | 租户 | 重点 |
| --- | --- | --- |
| T01 | 星河未来成长中心 | 全功能主演示 |
| T02 | 云杉学业服务中心 | 知识库与运营 |
| T03 | 拾光艺术成长营 | 学习与提醒 |
| T04 | 远航国际语言学院 | 财务与办事 |
| T05 | 启明星科学探索馆 | AI 与人工协作 |

说明 `T01–T05` 是展示编号，底层仍是 UUID tenant_id；历史手工测试租户不混入录屏列表。

### 2:30–4:00：租户工作台

选择 T01 的“林小满家长”，进入租户工作台：

1. 展示已启用功能和本租户文档。
2. 展示人工客服入口和审计/死信运营数据。
3. 展示按会话统计的 token 与成本。
4. 指出新建管理员会一次性显示初始密码，登录时按租户 ID + 邮箱匹配。

### 4:00–8:30：客户八个闭环

点右上角“进入客户视角”，按页面顶部的预设问法演示：

1. `你们有哪些课程？` — RAG 回答和来源。
2. `打开我的课表` — 回答下方直接出现功能按钮。
3. `查询订单和发票` — 脱敏财务数据。
4. `我要请假` — 打开确定性表单和幂等指令。
5. `帮我关闭自动续费` — 展示二次确认；已关闭时返回人话，不暴露 HTTP 500。
6. `创建上课提醒` — 回答下方设置时间与事项；重复内容拒绝重复创建。
7. `转人工客服` — 演示不在线状态和留言板。
8. `隔壁公司的课程和优惠是什么？` — 回答无法访问其他租户，证明隔离而不只是口头宣称。

### 8:30–10:00：真实租户流程

返回首页，进入“新建租户”，在独立的“注册 / 登录”页选择注册：

1. 注册新租户，只勾选部分功能，提交后自动进入独立工作台。
2. 展示工作台不存在注册、登录、再建租户和客户视角入口，证明页面角色边界清晰。
3. 展示系统为新租户生成的 4 个虚构客户；它们是真实 tenant_id 过滤后的数据库记录，不是前端写死卡片。
4. 批量上传 Markdown/TXT，展示标题、前三行与悬浮全文。
5. 在租户客服测试区验证真实 LLM；未启用人工时输入“转人工”，展示“当前租户未配置人工服务”。

### 10:00–11:30：测试与故障证据

展示命令和现有报告，不在录屏时现场等待整套压测：

```bash
make test
make evaluate
```

打开 `report/压测报告.md`、`report/故障注入报告.md`、`evaluation/report.json`。说明自动测试强制 Mock LLM，不会意外消耗 DeepSeek 额度。

### 11:30–12:30：主动说边界

> 本地已完成面试规模压测和故障注入，但没有在固定 8C16G 上跑满 500 WS / 200 msg/s / 5 分钟和 1000 msg/s 突发，所以我不把当前报告宣称为生产容量承诺。如果上线，下一步是固定资源基准、Prometheus/Grafana 看板和供应商限额联调。

这段不会扣分，反而证明你能区分演示证据与生产承诺。

## 现场被抽问时的回答主线

- 为什么用 NATS：JetStream 提供至少一次投递与积压，与 transactional outbox 一起关闭 DB/队列双写窗口。
- 为什么 LLM 不直接调工具：财务和写操作需要可证明的鉴权、Schema、幂等和审计。
- 如何防串租户：身份只取 JWT，业务 SQL 和 Qdrant 都强制 tenant_id，测试直接用越权反例证伪。
- 如何防 DeepSeek 高并发断连：Redis 共享准入池限制 600 在途和 20 starts/s，等待请求不先建 TCP 连接。
- coding agent 做了什么：用于生成脚手架、测试候选和文档；人工负责需求映射、安全边界、失败测试、Mock/真实依赖分离和最终取舍。
