## raw/ 子目录（压测与验收原始证据）

`raw/` 里是压测和验收跑出的**原始文件**，不逐个编号，按命名规则即可读懂。两类文件：

### 压测场景文件（Locust）

命名 = `<场景前缀>_<类型>.csv`，四个类型：

| 后缀 | 含义 |
| --- | --- |
| `*_stats.csv` | 该场景的**汇总统计**（每类请求的 RPS、失败数、P50/P95/P99 延迟等）。 |
| `*_stats_history.csv` | **逐秒时序**（每秒用户数、RPS、分位数），用于画曲线/定位拐点。 |
| `*_exceptions.csv` | 压测期间的**异常记录**（Count / Message / Traceback）。 |
| `*_failures.csv` | **失败记录**（Method / Name / Error / 出现次数）。 |

场景前缀对应的压测目标：

| 前缀 | 场景 |
| --- | --- |
| `stable` / `stable200*` | 200 msg/s 稳定流（Word NFR-1 目标） |
| `burst` / `burst1000*` | 1000 msg/s 突发流（Word NFR-1 目标） |
| `finance` / `finance100*` | 100 QPS 财务查询（Word §6.4 目标） |
| `llm-timeout` / `llm-timeout-20*` | 20% Mock LLM 超时的降级链路 |
| `ws-smoke` / `ws500*` | WebSocket smoke / 500 长连接 |
| `outbox-optimized-*` | Outbox 优化后的复测轮（`-exact` 精确 200、`-final` 终轮、`-3api` 三副本分流） |
| `outbox-tuning-*` | Outbox 调参实验轮 |
| `stable200-current-2w/4w*` | 不同 worker 数（2w/4w）及 `-valid`/`-tuned` 变体轮 |

### 观测与日志

| 文件 | 含义 |
| --- | --- |
| `*-observability.jsonl` | 逐采样点的**容器指标**（CPU/内存/网络）与 **NATS consumer 积压**（pending/ack_pending/redelivered），用于证明"停压即排空、无积压"。 |
| `acceptance-20260924*.log` | 验收门禁（隔离 Compose 项目）的完整运行日志。 |
| `loadtest-backlog-final.json` | 压测结束时的最终积压快照。 |

> 说明：大量 `*_exceptions.csv` / `*_failures.csv` 只有 30 字节（空表头），表示该轮**零异常 / 零失败**，属于正常证据而非异常现象。
